לפני שמעלים עוד אפליקציה

4 הסקילים ל-Claude Code

כל הקישורים ופקודות ההתקנה מהסרטון. כל הארבעה בחינם, צריך רק את Claude Code.

איך מתקינים

  1. פותחים את הטרמינל.
  2. מדביקים את הפקודות של כל סקיל.
  3. פותחים סשן חדש ב-Claude Code.
מעדיפים הכל בבת אחת? כל ההתקנות בפקודה אחת
01

i-have-adhd

59,723 כוכבים · MIT

קלוד מפסיק לחפור. במקום פסקאות ארוכות אתם מקבלים ישר את התשובה, ואחריה צעדים ממוספרים.

התקנה
claude plugin marketplace add ayghri/i-have-adhd claude plugin install i-have-adhd@i-have-adhd

איך משתמשים כותבים /i-have-adhd בשיחה.

הריפו בגיטהאב

02

unslop

5,141 כוכבים · CC BY 4.0

לוקח ממשק שנראה כאילו AI בנה אותו, מוצא גרדיאנטים סגולים, אימוג׳ים, כותרות צועקות ורווחים לא אחידים, ומעצב אותו מחדש עם אופי משלו. הוא מציע כיוון לפני שהוא משנה משהו.

התקנה
git clone https://github.com/heydamir/unslop mkdir -p ~/.claude/skills && cp -r unslop/skills/unslop ~/.claude/skills/

איך משתמשים כותבים /unslop this dashboard, או /unslop my landing page.

הריפו בגיטהאב

03

Ponytail

182,312 כוכבים · MIT

קלוד חושב כמו הסניור הכי עצלן בצוות: כותב רק מה שצריך. בבנצ׳מרק של הפרויקט עצמו: 53% פחות קוד, 45% פחות טוקני פלט, וכל 30 ריצות האבטחה עברו.

התקנה
claude plugin marketplace add DietrichGebert/ponytail claude plugin install ponytail@ponytail

איך משתמשים כותבים /ponytail כדי להפעיל, ו-/ponytail-help לכל הפקודות.

הריפו בגיטהאב

04

Floorplan

1,908 כוכבים · MIT · צריך Node 18 ומעלה

קורא את הקוד ומצייר מפה של כל האפליקציה בשפה פשוטה. ה-Health check שלו תופס מפתחות בקוד, טבלאות בסופבייס שכל אחד יכול לקרוא, חוקי Firebase פתוחים, webhooks של Stripe שאפשר לזייף וכתובות בלי התחברות, ולכל ממצא יש תיקון מוכן להדבקה.

התקנה
claude plugin marketplace add haydenschmitty/floorplan claude plugin install floorplan@floorplan

איך משתמשים בסשן חדש כותבים Make me a floorplan of this app.

הריפו בגיטהאב
